# Ainstien

This is a Flask-based web application that uses Machine Learning to analyze company fundamental data and suggest potential trades.

---

### 🚀 Setup & Environment Management

We are using **`uv`** for this project. It is a modern, high-performance Python package manager that replaces `pip` and `venv` for better speed and consistency on our Macs.

#### 1. Initial Installation

- **Install `uv`**: Run the following command in your terminal:
  ```bash
  curl -LsSf [https://astral.sh/uv/install.sh](https://astral.sh/uv/install.sh) | sh
  ```
- **Restart Terminal**: Close and reopen your terminal so the `uv` command is recognized.
- **First Time Setup**: If you just cloned the repo, run the following to create the virtual environment and install all dependencies:
  ```bash
  uv sync
  ```

#### 2. Daily Workflow

- **After git pull**: Always run `uv sync` to ensure your local packages match any changes made to the project.
  ```bash
  uv sync
  ```
- **Activate Environment**: Before running the app or scripts, activate the virtual environment:
  ```bash
  source .venv/bin/activate
  ```
- **Adding Packages**: If we need a new library (e.g., `yfinance`), do not use `pip`. Use:
  ```bash
  uv add <package_name>
  ```

#### 3. Database & API Setup

- **Environment Variables**: Create a `.env` file in the root directory and add your SimFin API key:
  ```text
  SIMFIN_API_KEY=your_actual_key_here
  ```
- **Seed the Database**: To fetch fundamental data from SimFin and populate your local SQLite database, run:
  ```bash
  python seed.py
  ```

#### 4. Project Configuration

- **`pyproject.toml`**: This was created via `uv init` and serves as our project blueprint.
- **`uv.lock`**: This is our "Source of Truth" for exact package versions. **Do not edit this file manually.**
